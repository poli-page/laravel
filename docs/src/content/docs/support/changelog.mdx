## Versioning

`poli-page/laravel` shares its major.minor with the Poli Page API: package `0.13.x` talks to API `0.13` and requires `poli-page/sdk` `^0.13.0`. Patch numbers are free. A change of the API contract, a new feature, and a raise of the minimum PHP or Laravel version are each a minor.
